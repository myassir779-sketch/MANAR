## Local preview
Open `index.html` in a modern browser. A local static server can be used if browser clipboard behavior requires localhost/HTTPS.

## Future free hosting review
Before deploying, verify the current plan terms, usage limits, build behavior, account requirements, data processing terms, and whether a payment method is required. Do not proceed if charges can be triggered or terms cannot be verified. Do not buy a domain; use a free provider subdomain if appropriate.

## Owner action
If a provider requires account creation or a user-controlled login, stop and give the owner exact steps. Never invent credentials or accept financial terms on the owner's behalf.
