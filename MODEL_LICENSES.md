# Model and data license register

## Phase 1

No translation model or translation dataset is bundled or downloaded. No model license is claimed. The interface's language selector is not evidence of translation support.

## Gate before adding a model

For every exact model repository and revision, record:
- Canonical model name, publisher, repository and revision.
- License file and interpretation; commercial-use permission must be verified separately.
- Supported source/target language directions and evidence.
- Model and tokenizer download size, runtime requirements, and browser compatibility.
- Any restrictions on redistribution, hosted use, attribution, or derivative works.
- Test corpus, examples, results, known failure modes, and reviewer.
- Date checked.

Do not enable a model until these checks are complete. Similar model families may have different licenses.
