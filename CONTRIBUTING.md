# Contributing to MANAR

1. Keep changes small and testable.
2. Never add paid services, payment flows, secrets, or billable deployments without explicit owner approval.
3. For translation models, update `MODEL_LICENSES.md` and `docs/SUPPORTED_LANGUAGES.md` with evidence before enabling a language pair.
4. Never fabricate translation output or report tests as passed unless actually run.
5. Prefer accessible semantic HTML, keyboard support, clear error states, and no unnecessary dependencies.
