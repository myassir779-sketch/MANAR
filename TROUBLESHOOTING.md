# Troubleshooting

- **Translate reports unavailable:** expected in Phase 1; no real model is connected.
- **Glossary does not persist:** check whether the browser allows local storage and whether private browsing or storage limits interfere.
- **Clipboard does not work:** some browsers require localhost/HTTPS. Manually select and copy text as a fallback.
- **Font looks different/offline:** the optional remote font stylesheet may not load; system fallbacks should be used. Remove the Google Fonts `@import` for no external request.
- **Mobile layout:** use a current browser and refresh after updating files.
