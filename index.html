م

MANAR Language Studio

Muundo huu una workspace ya tafsiri, miradi, translation memory, glossary, QA, subtitle checks, text tools, history na admin console ya ndani.

Vipengele vinavyofanya kazi sasa

• Usimamizi wa miradi na hali yake • Translation memory ya ndani • Glossary • QA ya namba/placeholders/tagi • Zana za maandishi • Uingizaji wa faili za maandishi • Subtitle validation • Export/import backup • Audit log ya ndani.

Bado havijatekelezwa

Injini halisi ya tafsiri ya mashine/AI, akaunti salama za watumiaji, ushirikiano wa timu kwa wakati halisi, uchakataji wa PDF/DOCX, cloud sync na deployment ya public website. Hakuna matokeo ya tafsiri ya kubuni yanayotolewa.

Jinsi ya kuendesha

Fungua index.html kupitia local web server au tumia npm run serve baada ya kuongeza server script (kwa sasa tumia npx serve . ikiwa imewekwa). Data ya mfano huanza tupu na huhifadhiwa kwenye browser.

Vyanzo vya muundo

Vipengele vya CAT/TMS vimepangwa kwa kuzingatia translation memory, terminology, workflow, file formats na QA kama vipengele muhimu vya jukwaa la tafsiri. Hakuna mtoa huduma wa tafsiri wa nje aliyewashwa.
