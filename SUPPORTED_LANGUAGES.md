# Supported languages

## Phase 1 status

**No translation language pair is currently verified or enabled.**

The UI offers English, Swahili, Arabic, French, Spanish, Portuguese, and German as selectable interface labels. This is not a claim that a translation engine supports those languages. “Detect language” is a UI option only; automatic detection is not implemented.

## Future registry requirements

For each pair, document source and target language codes, exact model/revision, license, runtime, evaluation samples, reviewer, limitations, and date checked. Mark a pair as supported only after a real integration test has passed.
